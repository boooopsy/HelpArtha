# Raw WebGL Lighted Prism (P20_1)

**Module:** WebGL, Compute Shaders & Three.js 3D Telemetry Panels (`module20_webgl_shaders`)  
**Classification:** Alpha (Tactile)  

## 1. Project Objective
Render an interactive 3D prism in raw WebGL without external libraries, compiling custom shaders.

## 2. Mental Model & Physical Analogy
WebGL exposes graphics hardware directly inside the browser. Arrays of 3D coordinates are uploaded to GPU buffers, where vertex and fragment shaders render them in parallel.

## 3. Bill of Materials / Tools
WebGL 2.0 compatible browser, GPU with WebGL hardware acceleration.
