# Pure-Python Naive Bayes Classifier (P06_3)

**Module:** Discrete Probability, Information Theory & Entropy (`module06_probability_entropy`)  
**Classification:** Gamma (Capstone)  

## 1. Project Objective
Build a text classification engine computing log-likelihood probabilities over text files.

## 2. Mental Model & Physical Analogy
Information is the measure of surprise. If an event is guaranteed, its information content is zero. Probability measures expectation; entropy quantifies average system-wide uncertainty.

## 3. Bill of Materials / Tools
Galton board, balanced dice, physical coin set.
