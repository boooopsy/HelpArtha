# Mini-Lang Compiler (P17_3)

**Module:** Compiler Construction, Lexing, ASTs & Code Generation (`module17_compiler_construction`)  
**Classification:** Gamma (Capstone)  

## 1. Project Objective
Build an end-to-end compiler for a custom imperative language compiling directly to valid RISC-V assembly.

## 2. Mental Model & Physical Analogy
A compiler translates human intent into machine execution by converting text into a stream of tokens, structuring tokens into a syntax tree, and flattening that tree into assembly.

## 3. Bill of Materials / Tools
Text editor, Graphviz for AST visualization, Python/C build environment.
