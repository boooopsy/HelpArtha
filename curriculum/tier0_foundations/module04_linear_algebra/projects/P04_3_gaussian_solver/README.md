# Bare Gaussian Linear System Solver (P04_3)

**Module:** Linear Algebra, Coordinate Systems & Affine Transforms (`module04_linear_algebra`)  
**Classification:** Gamma (Capstone)  

## 1. Project Objective
Build a linear solver in C implementing Gaussian elimination with partial pivoting.

## 2. Mental Model & Physical Analogy
A vector is a physical arrow on a grid; a matrix is a dynamic transformation that stretches, rotates, or shears space itself.

## 3. Bill of Materials / Tools
Coordinate pegboard, elastic bands for basis vectors.
