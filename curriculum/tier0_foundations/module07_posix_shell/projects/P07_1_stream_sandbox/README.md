# Stream Redirection Sandbox (P07_1)

**Module:** POSIX OS Mechanics, System Streams & Shell Tools (`module07_posix_shell`)  
**Classification:** Alpha (Tactile)  

## 1. Project Objective
CLI workbench visualizing data flowing through file descriptors and kernel pipe buffers.

## 2. Mental Model & Physical Analogy
In Unix, everything is a stream of bytes accessible via an integer file descriptor. Software programs are modular components connected with pipes.

## 3. Bill of Materials / Tools
Linux terminal environment, USB serial debug cable.
