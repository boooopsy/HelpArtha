# 2D Gradient Descent Visualizer (P05_3)

**Module:** Calculus of Rates, Gradients & Computational DAGs (`module05_calculus`)  
**Classification:** Gamma (Capstone)  

## 1. Project Objective
Plot optimization trajectories over non-convex functions across varying learning rates.

## 2. Mental Model & Physical Analogy
A derivative is an optical zoom into a curve until it becomes a straight line. Multi-dimensional gradients point in the direction of steepest ascent.

## 3. Bill of Materials / Tools
Graphing calculator, 3D surface clay models.
