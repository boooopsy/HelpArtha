# Decentralized State Machine Engine (P26_3)

**Module:** Cryptography, Identity & Web3 State Machines (`module26_crypto_state_machines`)  
**Classification:** Gamma (Capstone)  

## 1. Project Objective
Build a replicated ledger engine processing Ed25519-signed transactions and validating state roots.

## 2. Mental Model & Physical Analogy
A decentralized state machine is a shared virtual computer. Cryptographic keys authenticate identity, digital signatures validate transactions, and cryptographic hashes secure the shared ledger.

## 3. Bill of Materials / Tools
Local blockchain node simulator, hardware security key / smartcard.
