# Module 04: Linear Algebra, Coordinate Systems & Affine Transforms

**Tier:** `tier0_foundations`  
**Status:** Verified Master Specification  

## 1. Concrete Mental Model
>A vector is a physical arrow on a grid; a matrix is a dynamic transformation that stretches, rotates, or shears space itself.

## 2. Core Primitives
Vector spaces, L1 and L2 norms, dot products as projections, cosine similarity, cross products; matrices as linear coordinate transformers, matrix multiplication as composition, determinants as area/volume scaling, rank, Gaussian elimination with partial pivoting.

## 3. Physical & Virtual Workbenches (BOM)
Coordinate pegboard, elastic bands for basis vectors.
