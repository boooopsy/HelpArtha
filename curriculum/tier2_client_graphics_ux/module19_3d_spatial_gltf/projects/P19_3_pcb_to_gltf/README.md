# Automated PCB-to-glTF Pipeline (P19_3)

**Module:** 3D Spatial Modeling & Asset Pipelines (Blender to glTF) (`module19_3d_spatial_gltf`)  
**Classification:** Gamma (Capstone)  

## 1. Project Objective
Write a Python script for Blender that parses board dimensions and generates a detailed 3D enclosure.

## 2. Mental Model & Physical Analogy
3D digital objects are wireframe shells of interconnected triangles. The orientation of their surface normals governs how light interacts with the material.

## 3. Bill of Materials / Tools
Blender 4.x, glTF 2.0 validator, 3-button mouse with scroll wheel.
