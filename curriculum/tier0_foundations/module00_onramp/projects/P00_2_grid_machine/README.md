# Token Grid State Machine (P00_2)

**Module:** The Concrete On-Ramp (`module00_onramp`)  
**Classification:** Beta (Milestone)  

## 1. Project Objective
Build an ASCII 2D grid runner in Python executing an in-place bubble sort on an array of 8 cells with explicit pointer tracking.

## 2. Mental Model & Physical Analogy
Computation is physical motion. Pointers are positions on a floor grid; logic bits are mechanical switches redirected by falling marbles; touch typing is procedural muscle memory.

## 3. Bill of Materials / Tools
Turing Tumble board & simulator, 8x8 numbered wooden token grid with colored markers, mechanical keyboard.
